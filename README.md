# РПД «Технологии разработки программного обеспечения»

Рабочая программа дисциплины (упрощённая форма на основе компетентностно-ролевой модели). Команда № 28.

## Паспорт

- Направление: 09.03.04 «Программная инженерия», бакалавриат
- Семестр: 4 (2 семестр 2 курса)
- Трудоёмкость: 4 з.е. / 144 ак. ч. (лекции — 16, лабораторные — 48, СРС — 80)
- Промежуточная аттестация: зачёт с оценкой — защита командного программного проекта
- Компетенции КРМ 3.0: PL-1 (индикаторы 1.1–1.3), SS-2 (индикаторы 2.1, 2.2)
- Уровни: PL-1.1 — С; PL-1.2, PL-1.3, SS-2.1, SS-2.2 — Б (уровни в занятиях не смешиваются)
- Роль КРМ (справочно): ML Engineer

## Ключевая особенность

Сквозной командный проект (команды 3–5 человек) со спринтовой организацией, синхронизированный с модулями дисциплины; репозиторий Git — единая среда работы (задачи, код-ревью, автоматические проверки). Оценка сочетает командный результат и индивидуальный вклад.

## Структура (модули)

1. Жизненный цикл ПО и организация командной разработки
2. Инструменты коллективной разработки (Git, код-ревью)
3. Проектирование и серверная разработка на Python (FastAPI)
4. Качество ПО: тестирование, отладка, документирование
5. Обработка данных в приложении (ETL)
6. Командный программный проект (сквозной)

## Состав документа

Разделы 1–7: паспорт, цель и задачи, компетенции и индикаторы, таблица «структура — содержание — результаты», пре-/постреквизиты и место в ОП, образовательные технологии, краткая система оценки (состав будущего ФОС). Разделы 8–12: литература, интернет-ресурсы, методические указания, информационные технологии и ПО, материально-техническая база.
